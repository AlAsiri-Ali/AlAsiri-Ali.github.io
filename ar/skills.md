<p class="aa-lede">لا تستخدم هذه الصفحة نسبًا ذاتية أو مستويات مبالغًا فيها؛ بل تربط كل قدرة بأعمال توضح كيفية تطبيقها.</p>

| القدرة | الأدوات والمنهجيات | الدليل |
|---|---|---|
| RAG موثوق | استرجاع هجين، BM25، TF-IDF، تطبيع نصي، استشهادات، توليد مضبوط | [GovRAG Copilot](/ar/projects/govrag-copilot/)، [Asthma RAG](/ar/projects/asthma-rag-diagnostic-assistant/) |
| تقييم النماذج | خطوط أساس، بذور متكررة، ROC/PR، macro F1، أخطاء الفئات، اختبار انتقال البيانات | [متانة كشف التزييف](/ar/projects/deepfake-detection-compression/)، [الروابط الخبيثة](/ar/projects/malicious-url-detection-ml/) |
| الرؤية الحاسوبية | PyTorch، نقل التعلم، YOLOv8، OpenCV، تمويه الخصوصية، خصائص DCT | [كشف PPE](/ar/projects/ppe-safety-detection/)، [أمراض الكاجو](/ar/projects/cashew-leaf-disease-classification/) |
| معالجة اللغة وتحليل النص | معالجة العربية والإنجليزية، TF-IDF، Word2Vec/AraVec، LSTM/BiLSTM، Transformers | [المشاعر العربية](/ar/projects/arabic-sentiment-aravec-lstm/)، [مشاعر Galaxy](/ar/projects/android-galaxy-sentiment-analysis-nlp/) |
| البيانات ونمذجة القرار | Pandas، هندسة الخصائص، مراجعة عدم التوازن، التجزئة، الاختبار الخلفي، التفسير | [تحليلات التجزئة](/ar/projects/retail-segmentation-market-basket/)، [أنظمة السوق](/ar/projects/sp500-market-regime-classification/) |
| النمذجة الأولية والتنفيذ | Python، Git/GitHub، اختبارات، Gradio، Streamlit، هياكل مشاريع قابلة لإعادة الاستخدام | [الأعمال المختارة](/ar/projects/) |

## مبادئ العمل

- تحديد القرار والمستخدم قبل اختيار النموذج.
- المقارنة بخطوط أساس واضحة وشرح المفاضلات بدل الاكتفاء بمقياس واحد.
- التعامل مع الاستشهادات والخصوصية والمراقبة وحالات الفشل كمتطلبات نظام.
- إبقاء المستودعات قابلة للفحص وإعادة التشغيل ومكتملة التوثيق.
